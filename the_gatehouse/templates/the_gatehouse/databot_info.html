In the settings of your League or Tournament select your guild from the guild dropdown. This will link the two and give you access to the automation features.

3
Set the Channels

{% if user_is_authenticated %}From the Manage your Guilds page edit your guild.{% else %}From the Manage your Guilds page edit your guild.{% endif %} Near the bottom you will see your League or Tournament listed, where you can set three channels:

  • #results Once a game is completed a message will post here.
  • #schedule If a match is scheduled a message with the scheduled time will be posted here.
  • #threads If you create matches ahead of time on the Series page you will see an option to create threads for each game. Choosing it creates a new thread here and pings each of the players.

Get notified in Discord

If you share a server with the Root Databot, it can send you a direct message when things you care about happen on the Root Database.

A game you played in is recorded.
A game is recorded using a faction you designed.
A faction you submitted is approved, or a survey you made gets a response.
A new faction, map or deck is posted.
A faction is marked as “Stable.”
